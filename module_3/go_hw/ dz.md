Задание 1. Калькулятор с проверкой

Пользователь вводит два числа и одну из арифметических операций: +, -, * или /.

Реализуйте программу, которая выполняет выбранное вычисление. При делении предусмотрите проверку деления на ноль.

Отрабатываемые навыки: switch, if, арифметические операции.



Задание 2. Анализ числа
 
Введите число N.

Реализуйте программу, которая определяет:

    положительное число или отрицательное;

    чётное число или нечётное;

    делится ли число на 3 и на 5.

Отрабатываемые навыки: условные операторы, оператор %.



Задание 3. Сумма и среднее от 1 до N

Пользователь вводит число N.

Реализуйте программу, которая вычисляет:

    сумму всех чисел от 1 до N;

    среднее значение этих чисел.

Отрабатываемые навыки: цикл for, накопление суммы, тип float64.



Задание 4. Таблица умножения через функцию

Создайте функцию printTable(n), которая выводит таблицу умножения для числа от 1 до 10.

Отрабатываемые навыки: функции, цикл for.



Задание 5. Максимум из N чисел

Пользователь сначала вводит количество чисел N, затем последовательно вводит N чисел.

Реализуйте программу, которая определяет максимальное и минимальное значения среди введённых чисел.

Отрабатываемые навыки: цикл, пользовательский ввод, сравнение значений.



Задание 6. Количество положительных и отрицательных чисел

Введите N чисел.

Реализуйте программу, которая отдельно подсчитывает:

    количество положительных чисел;

    количество отрицательных чисел;

    количество нулей.

Отрабатываемые навыки: цикл for, условные конструкции if / else, счётчики.



Задание 7. Сумма только подходящих чисел

Реализуйте программу, которая вычисляет сумму чисел от 1 до N, одновременно удовлетворяющих двум условиям:

    число является чётным;

    число делится на 3.

Отрабатываемые навыки: цикл for, логический оператор &&, оператор %.



Задание 8. Проверка простого числа

Создайте функцию isPrime(n int) bool, которая определяет, является ли переданное число простым.

Отрабатываемые навыки: функции, циклы, оператор return, условные конструкции.



Задание 9. Мини-банкомат

Реализуйте программу, в которой пользователь вводит баланс и выбирает одно из действий:

    Посмотреть баланс.

    Пополнить баланс.

    Снять средства.

При снятии средств предусмотрите проверку достаточности денег на балансе.

Отрабатываемые навыки: switch, if, арифметические операции.



Задание 10. Статистика последовательности

Введите N чисел.

Реализуйте программу, которая рассчитывает и выводит:

    сумму всех введённых чисел;

    среднее значение;

    максимальное значение;

    минимальное значение;

    количество чётных чисел;

    количество нечётных чисел.

Отрабатываемые навыки: комплексное применение изученных конструкций языка Go.
